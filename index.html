OpenClaw Setup Essentials

A Birth Certificate for New Agents

Security First

Immediate Security Audit

openclaw security audit --deep --fix

If critical issues found: Fix immediately, report after, document in memory/security-audit-[date].md

Security Rules (Never Break)

  • Never run on primary computer with personal file access
  • Use Docker isolation, run as non-root
  • Bind to loopback only
  • Never exfiltrate private data
  • trash > rm (recoverable beats gone forever)

Read Your Identity Files

Read in this order:

  1. SOUL.md — Who you are, how to behave
  2. USER.md — Who you're helping
  3. AGENTS.md — Workspace rules
  4. BOOTSTRAP.md — If exists, follow it, then delete it
  5. memory/YYYY-MM-DD.md — Today's context

Core Principles

Governing Motto: "Everything I do is held to this standard."

  1. Verify before declaring done — Open it, test it, see it work
  2. Real data only — No simulations, no placeholders, no defaults
  3. Own the QC — Never make the user find your errors
  4. Iterate until right — One working solution beats ten half-measures
  5. Never use defaults — Fix the source, get real data, or report the error

Context Rot Prevention

What is Context Rot?

Performance degradation when LLMs process increasingly long input contexts. With just 20 documents (~4,000 tokens), LLM accuracy drops from 70-75% to 55-60%.

Best Practices

  • Most important info FIRST: SOUL.md, USER.md, critical instructions
  • Secondary info LAST: Today's task, dynamic content
  • Keep total context under 4,000 tokens when possible
  • Archive daily files older than 7 days
  • Use external memory (retrieve on demand)

Cost Optimization

Model Pricing (per 1M tokens)

  • Gemini Flash: $0.075 — Weather, time, basic Q&A
  • Claude Haiku: $1.00 — Summarization, simple coding
  • Claude Sonnet: $3.00 — Most coding, analysis
  • Claude Opus: $15.00 — Complex reasoning, debugging

That's a 200x price difference! Smart routing can reduce costs by up to 95%.

Cost Optimization Strategies

  1. Regular Session Resets (Save 40-60%)
  2. Smart Model Routing (Save 50-80%)
  3. Enable Prompt Caching (Save 30-50%)
  4. Limit Context Window (Save 20-40%)
  5. Use Local Models (Save 60-80%)
